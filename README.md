📊 Life Dashboard (人生責任財務儀表板)

Life Dashboard 是一款專為現代人設計的「防護優先型」個人財務管理單頁應用程式 (SPA)。
有別於市面上單純記流水帳的 APP，本系統將 「固定責任」 與 「家庭支援」 視為理財的核心。透過「先扣除責任，再分配閒錢」的精算引擎，幫助使用者在負擔現實壓力的同時，依然能安心地為夢想與未來進行儲蓄。

✨ 核心特色 (Key Features)

1. 🛡️ 淨額閒錢精算引擎 (Net Allocatable Budget)

實境導向：不再使用虛幻的「預估月薪」，系統允許每月輸入「實際入帳薪資」。

優先扣除：薪資自動優先扣除當月活躍的「固定責任」與「家庭支援」。

精準分配：計算出真正的「可用閒錢」後，才根據自訂的黃金比例（如：生活 50%、儲蓄 20%、投資 15%、娛樂 15%）給出預算指導。

2. 📋 責任生命週期管理 (Responsibility Lifecycle)

跨月自動重置：每個月初，所有責任項目會自動恢復為「待繳納」狀態。

一鍵自動記帳 (Auto Ledger)：繳納責任只需「打勾 ✔️」，系統自動跳出帳戶選擇，並瞬間生成記帳明細、扣除帳戶餘額，三位一體無縫連動。

期間限定支援：支援設定責任的「開始月份」與「結束月份」（例如分期付款），過期自動從清單隱藏，確保未來預估準確。

3. 🏦 屬性隔離帳戶 (Account Isolation)

支援建立多個實體或數位帳戶，並可指派屬性：

日常現金流：參與每日生存雷達額度計算。

儲備/預備金：隔離保護，不計入日常可花費餘額。

長期投資：隔離保護，專注資產成長。

專屬轉帳機制：同儕帳戶互轉不列入收支報表，保持消費數據 100% 乾淨。

4. 🔮 戰略模擬與防禦金字塔 (Strategy & Goals)

未來走勢預測：根據當前儲蓄力，自動推算未來 6 個月的總資產走勢折線圖。

決策戰略模擬器：透過拉桿動態模擬「加薪」或「節流（如停扣訂閱、減少孝親）」，即時顯示一年後存款的增減差異。

跨年度防護金字塔：將理財目標分為三層（安全預備金 ➔ 大額負擔 ➔ 夢想成長），底層未滿時上層會顯示鎖定，引導循序漸進的健康理財觀。

5. 🔒 極致隱私與流暢體驗

零後端架構：所有資料皆透過 localStorage 儲存於使用者設備，100% 離線運行，無隱私外洩風險。

高效能單頁應用 (SPA)：無頁面刷新卡頓。內建 Canvas Destroy 機制與資料快取，即便累積大量交易紀錄，切換報表與首頁依然如絲般滑順。

自訂隱私鎖：支援啟動密碼驗證 (Onboarding)，保護個人財務隱私。

🚀 快速開始 (Quick Start)

本系統採純前端無依賴架構 (Vanilla JS + HTML5)，不需安裝 Node.js 或任何資料庫。

下載 index.html 檔案。

使用任何現代瀏覽器（Chrome, Safari, Edge, Safari iOS）直接雙擊開啟該檔案。

按照初次見面引導 (Onboarding) 輸入您的稱呼與密碼。

點擊右上角 ⚙️ 設定您的發薪日與資產分配比例。

開始記帳與規劃！

🛠️ 技術堆疊 (Tech Stack)

核心語言：HTML5, CSS3, Vanilla JavaScript (ES6+)

樣式框架：Tailwind CSS (CDN) - 用於快速且現代的響應式 (RWD) 排版設計。

字體庫：Google Fonts (Noto Sans TC, DM Mono)

圖表庫：Chart.js - 負責繪製支出圓餅圖與資產走勢折線圖。

動態特效：Canvas Confetti - 提供目標達成時的彩帶噴發視覺回饋。

📝 理財哲學聲明 (Philosophy)

這套系統的設計初衷，是為了解決「負重前行者」的財務焦慮：

「當我有房租、有學貸、還要給家裡錢的時候，傳統的『收入 - 支出 = 儲蓄』根本無法反映我的現實。」

因此，Life Dashboard 強制您直面固定責任。當看著責任一項一項被打勾結清，您會清楚知道剩下的每一塊錢，都是您可以完全安心運用、投資、甚至拿來犒賞自己的「真・閒錢」。理財，從安心開始。
