# 📊 Life Dashboard (人生責任財務儀表板)

**Life Dashboard** 是一款專為現代人設計的「防護優先型」個人財務管理單頁應用程式 (SPA)。
有別於市面上單純記流水帳的 APP，本系統將 **「固定責任」** 與 **「家庭支援」** 視為理財的核心。透過「先扣除責任，再分配閒錢」的精算引擎，幫助使用者在負擔現實壓力的同時，依然能安心地為夢想與未來進行儲蓄。

---

## ✨ 核心特色 (Key Features)

### 1. 🛡️ 淨額閒錢精算引擎 (Net Allocatable Budget)
* **實境導向**：不再使用虛幻的「預估月薪」，系統允許每月輸入「實際入帳薪資」。
* **優先扣除**：薪資自動優先扣除當月活躍的「固定責任」與「家庭支援」。
* **精準分配**：計算出真正的「可用閒錢」後，才根據自訂的黃金比例（如：生活 50%、儲蓄 20%、投資 15%、娛樂 15%）給出預算指導。

### 2. 🎯 滾動式生存雷達 (Rolling Envelope Engine)
* **每日預算標準**：系統根據本月的「生活閒錢」，自動計算出每日可以花費的安全標準。
* **結餘滾動累積**：如果您今天特別省錢，未花完的額度會化為「🟢 今日結餘」，並自動累積到明天，讓您看著能用的錢變多，存錢超有感！
* **防透支警告**：一旦今日花費超標，或者整體花費速度超越時間進度，雷達會立刻變紅，給予最即時的警惕。

### 3. 💰 結餘收割與自動存錢筒 (Harvesting)
* **虛擬小豬存錢筒**：系統預設內建「🐖 日常結餘存錢筒」。
* **一鍵收割**：當「今日結餘」有剩餘時，按下收割按鈕，這筆錢會瞬間從明天的預算中被鎖定，並自動轉入您的目標儲備帳戶。
* **儲蓄可視化**：內建「近半年儲蓄轉存統計圖表」，讓您每個月省下的每一分錢都化為視覺上的成就感。

### 4. 📋 責任生命週期管理 (Responsibility Lifecycle)
* **跨月自動重置**：每個月初，所有責任項目會自動恢復為「待繳納」狀態。
* **一鍵自動記帳 (Auto Ledger)**：繳納責任只需「打勾 ✔️」，系統自動跳出帳戶選擇，並瞬間生成記帳明細、扣除帳戶餘額，無縫連動。

### 5. 🧱 專款專用的目標金字塔 (Isolated Goals)
* **跨年度防護金字塔**：將理財目標分為三層（安全預備金 ➔ 大額負擔 ➔ 夢想成長）。
* **嚴格資金隔離**：金字塔進度**只會讀取**屬性為「儲備/預備金」或「長期投資」的帳戶。放在日常現金流裡的錢不會算入目標，杜絕「錢已經存夠」的財務錯覺。

### 6. 🔒 極致隱私與流暢體驗
* **零後端架構**：所有資料皆透過 `localStorage` 儲存於使用者設備，**100% 離線運行，無隱私外洩風險**。
* **高效能單頁應用 (SPA)**：無頁面刷新卡頓。內建快取與自動記憶體釋放機制，即便累積大量交易紀錄，操作依然如絲般滑順。
* **自訂隱私鎖**：支援啟動密碼驗證，保護個人財務隱私。

## 🚀 快速開始 (Quick Start)

本系統採純前端無依賴架構 (Vanilla JS + HTML5)，不需安裝 Node.js 或任何資料庫。

1. 下載 `index.html` 檔案。
2. 使用任何現代瀏覽器（Chrome, Safari, Edge, Safari iOS）直接雙擊開啟該檔案。
3. 按照初次見面引導 (Onboarding) 輸入您的稱呼與密碼。
4. 點擊右上角 `⚙️` 閱讀「產品使用說明」，並設定您的發薪日與資產分配比例。
5. 開始記帳與規劃！

## 🛠️ 技術堆疊 (Tech Stack)

* **核心語言**：HTML5, CSS3, Vanilla JavaScript (ES6+)
* **樣式框架**：[Tailwind CSS (CDN)](https://tailwindcss.com/) - 用於快速且現代的響應式 (RWD) 排版設計。
* **字體庫**：Google Fonts (Noto Sans TC, DM Mono)
* **圖表庫**：[Chart.js](https://www.chartjs.org/) - 負責繪製支出圓餅圖與儲蓄統計長條圖。
* **動態特效**：[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) - 提供目標達成時的彩帶噴發視覺回饋。

## 📝 理財哲學聲明 (Philosophy)

這套系統的設計初衷，是為了解決「負重前行者」的財務焦慮：
> *「當我有房租、有學貸、還要給家裡錢的時候，傳統的『收入 - 支出 = 儲蓄』根本無法反映我的現實。」*

因此，**Life Dashboard** 強制您直面固定責任。當看著責任一項一項被打勾結清，您會清楚知道剩下的每一塊錢，都是您可以完全安心運用、投資、甚至拿來犒賞自己的「真・閒錢」。理財，從安心開始。
